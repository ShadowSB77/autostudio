# Онлайн-запись в автосервис / детейлинг-студию

Одно приложение — много студий. Каждая студия живёт по своему адресу
`https://shadowsb77.github.io/autostudio/s/<название>/`, со своей иконкой и установкой на телефон.

## Как подготовить новую студию (≈5 минут)

```bash
pnpm install                                     # один раз
pnpm tenant:new mystudio --name "My Studio"      # папка tenants/mystudio/ с образцом
#   правим tenants/mystudio/tenant.json: название, адрес, телефон, цены, график, 3 карточки, цвет
#   кладём фото владельца: hero.jpg (главное), logo.png, gallery/01.jpg …
pnpm tenant:validate mystudio                    # проверка настроек и фото
pnpm tenant:publish mystudio                     # данные → база, код → GitHub (сайт соберётся за 1–2 мин)
pnpm tenant:owner mystudio owner@mail.ru         # вход в кабинет владельца (выдаст пароль)
pnpm tenant:check mystudio                       # проверка готовой ссылки → из «образца» в рабочий режим
```

`pnpm tenant:list` — все студии и их статус.

До `tenant:check` студия работает как **образец**: сверху плашка, записи помечаются как тестовые
и удаляются при переводе в рабочий режим.

Все настройки студии — в одном файле `tenants/<название>/tenant.json`. После публикации владелец
меняет услуги, цены, боксы, график, выходные, адрес, телефон, логотип, главное фото, три карточки и
фото работ в своём кабинете (`…/s/<название>/admin`). Повторный `tenant:publish` не перезаписывает
изменения владельца (только с `--force`).

Для команд нужен файл `.env.local` с `ADMIN_TOKEN=…` (не хранится в репозитории).

## Помощник (модель)

Секреты задаются в Supabase → Edge Functions → Secrets (в код сайта не попадают):

| Секрет | Что это |
|---|---|
| `OPENAI_API_KEY` | ключ OpenAI или совместимого сервиса |
| `OPENAI_BASE_URL` | адрес совместимого API (пусто — OpenAI) |
| `OPENAI_MODEL` | модель, по умолчанию `gpt-4o-mini` |
| `AI_DAILY_TOKENS_PER_STUDIO` | дневной лимит токенов на студию (300 000) |
| `AI_MAX_REPLY_TOKENS` | максимум токенов в ответе (450) |

Без ключа или при исчерпании лимита помощник отвечает по правилам из тех же данных базы.
Ограничение частоты: 15 вопросов за 10 минут с одного адреса, 300 в час на студию.

## Устройство

- `src/` — React + Vite + React Router, Astryx, Phosphor, TanStack Query, Zod, date-fns-tz, liquid-gl, PWA.
- `src/shared/schedule.ts` — расчёт свободного времени (график, выходные, боксы, длительность, подготовка,
  многодневные работы). Тот же код работает на сервере.
- `supabase/functions/` — `booking` (запись, отмена, перенос, напоминания), `assistant`, `ops` (команды студий),
  `reminders` (push за сутки, запускается каждые 10 минут).
- База: у каждой студии свои данные; права проверяются в базе (RLS) и в серверных функциях. Наложение записей в
  одном боксе запрещено ограничением базы, повторное нажатие «Подтвердить» не создаёт копию (ключ идемпотентности).
